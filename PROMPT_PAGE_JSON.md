# Промпт для распознавания страниц раскраски

Скопируй текст ниже в нейросеть вместе со сканами или фотографиями страниц.

```text
Ты анализируешь сканы страниц книги-раскраски.

На изображениях могут быть подписи в формате:
- «1 - stitch» — отдельная страница 1;
- «2-3 bebra» — один разворот, объединяющий страницы 2 и 3;
- «4 — cat» — отдельная страница 4.

Нужно определить номер или диапазон каждой страницы и сохранить подпись.
Верни только один валидный JSON-объект без markdown, комментариев и пояснений.

Правила формата:
1. Ключ отдельной страницы — строка с номером: "1".
2. Ключ разворота — строка с диапазоном через обычный дефис: "2-3".
3. Значение — строка с подписью после номера. Сохраняй подпись максимально близко к оригиналу,
   но убирай только лишние пробелы по краям.
4. Если подписи нет, используй пустую строку: "5": "".
5. Не создавай отдельные ключи для страниц, входящих в разворот. Для разворота должен быть только
   один ключ, например "2-3": "bebra".
6. Не придумывай номера и подписи. Если номер или диапазон неразборчивы, остановись и задай вопрос
   вместо выдачи предположения.
7. Ключи должны идти по возрастанию первой страницы.
8. Используй двойные кавычки. Одинарные кавычки запрещены: результат должен сразу приниматься
   стандартным JSON-парсером.

Пример правильного ответа:
{"1":"stitch","2-3":"bebra","4":"cat"}
```

Ожидаемый результат можно вставить в админке раскраски: «Импорт страниц из JSON».
